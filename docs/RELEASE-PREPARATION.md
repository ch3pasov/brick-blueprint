# Source distribution

The source distribution contains the renderer, the five-model vector portfolio, runnable examples, the English research edition and its numerical evidence. The release tool writes a local ZIP and an inventory of its exact contents. [Export and verification](RELEASE-TOOLING.md)

For a first Git commit, use the verified working tree. Build caches, local output folders and the Git database are excluded from the source archive. Verify the candidate and run the core suite from its extracted directory. [Test environment](CI.md)
